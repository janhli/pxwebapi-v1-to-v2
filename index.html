Oppdater gamle SSB-spørringer

SSB sitt gamle API blir lagt ned. Lim inn hele den gamle spørringen fra Power BI (M-koden) i boksen under, så oppdaterer vi den automatisk til det nye API-et — med de samme tabellene og verdiene som før. Har du bare selve JSON-spørringen, funker det også.

Du trenger ikke fortelle appen hva slags spørring det er — den kjenner det igjen selv.
Åpne i ny fane
Vis tekniske detaljer
  • Ny adresse har alltid formen https://<domene>/api/pxwebapi/v2/tables/<TABLE>/data, med lang som parameter.
  • Enkel nettadresse (GET): variabelvalg legges i URL-en som valueCodes[Dim]=csv (og codelist[Dim]=... ved aggregering/verdisett). Samme type som før (POST): samme valg legges i body som {"selection":[{"variableCode":...,"valueCodes":[...]}]}.
  • Rekkefølgen på variablene bevares. Braketter i parameternavn URL-encodes ikke.
  • Gammelt filter "all" → *, "top" → top(n), "agg_x:NAVN"/"vs:NAVN" → codelist=NAVN + valgte koder.
  • Power BI M-kode: kun selve Web.Contents(...)-kallet byttes ut — resten av M-koden (variabler, senere steg) rører vi ikke.
